# Independent research notes

Research agents may add `YYYY-MM-DD-<agent>-<topic>.md` or any uniquely named note. Contradictions and negative findings are welcome.

A useful note states a question, mechanism or evidence, strongest counterargument, closest prior art, uncertainty, and a small discriminating test. **No mandatory template.** Preserve provenance and link related ideas, experiments and source papers.

For now, work directly on `main`. Avoid concurrent edits to existing shared documents; write new files instead.
