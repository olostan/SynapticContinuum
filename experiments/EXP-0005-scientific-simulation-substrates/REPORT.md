## 4. Adversarial Falsification & Schema v2 Validator Results

All **24 unit tests** across `test_fixture_reproducibility.py`, `test_golden_oracle.py`, `test_falsification_adversarial.py`, and `test_schema_v2_validator.py` pass (`0.294s` total runtime):

1. **Oracle Falsification Rejections (`test_falsification_adversarial.py`):**
   - Non-positive synaptic delay (`delay_ms = 0.0` or `-1.0`) $\implies$ rejected with `CausalityViolationError`.
   - Negative or backward event timestamps (`t_ms = -0.1` or `3.0 -> 1.0`) $\implies$ rejected with `CausalityViolationError`.
   - Corrupted fixture SHA-256 $\implies$ rejected with `ChecksumMismatchError`.
   - Mixed or wrong physical units (`delay_s`, `weight_V`, `time_unit='s'`) $\implies$ rejected with `UnitMismatchError`.
   - Perturbed Golden B weight (`w = 0.35 mV` instead of `0.40 mV`) $\implies$ falsifies threshold crossing at $t=4.0\text{ ms}$ (`0` spikes).
   - Grid-quantized arrival timestamp (`t = 1.00 ms` vs `1.04 ms`) $\implies$ shifts $V(3.0^-)$ by $> 10^{-4}\text{ mV}$, breaking analytic tolerance and output trace SHA-256.
2. **Schema v2 Validator Rejections (`test_schema_v2_validator.py` & [`runs/wp00-validator-dryrun/validation_report.json`](runs/wp00-validator-dryrun/validation_report.json)):**
   - Rejects [`schemas/synthetic_validation_sample_NOT_A_RUN.json`](schemas/synthetic_validation_sample_NOT_A_RUN.json) unless `--allow-synthetic-sample` is explicitly passed.
   - Rejects any `null` field lacking an explicit explanation in `missing_or_unsupported_fields`.
   - Rejects mismatched `edges_fixture_sha256` / `events_fixture_sha256` or unknown `workload_instance_id`.
   - Rejects fixed-step solvers (`dt_ms != null`) claiming `semantic_classification = "equivalent-exact"`.
   - Rejects non-EXP-0004 backends claiming `parity_claim_with_exp0004 = true`.
   - Rejects zero-activity / allocation-only runs (`active_neurons_count == 0` or `committed_events == 0`) on active workloads.
   - Rejects `ROSS` records that omit `rolled_back_events` or `reexecuted_events`.
