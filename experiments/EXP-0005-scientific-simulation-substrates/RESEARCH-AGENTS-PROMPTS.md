# Independent research agents — copy-paste assignments

These are **independent research roles**, not permissions to edit each other's implementation. Each agent reads SPEC.md, ARCHITECTURES.md, WORKLOADS.md, EVIDENCE.md, SOURCES.md, EXP-0004 report/catalog, FOUNDATIONS.md and AGENTS.md; writes in a unique 'research/findings/exp0005-<role>/' directory on its own branch/PR; do not edit EXP-0004 nor adjudicate scientific acceptance. Cite original upstream source and commit/tag where possible. All output must separate published fact, inspected implementation, hypothesis and unmeasured assumption.

## A — Numerical semantics and model alignment skeptic
Investigate native LIF, subthreshold solvers, spike threshold/crossing, refractory, exact vs grid/timestep delivery, simultaneous events, synaptic STDP timing in NEST, Brian2 and Arbor. Provide a cross-API equation/units matrix plus executable-independent analytical expected values for two nontrivial fixtures; identify at least five ways apparent 'same network' benchmarking breaks. Propose a tolerance-vs-dt study and a precise 'not-comparable' label. Do NOT implement production adapter or run framework benchmark. Include sources/limitations and independent GO / CHANGES REQUESTED recommendation on numerical contract.

## B — PDES / Time Warp adversarial auditor
Read official ROSS API and source plus Time Warp and Chandy–Misra–Bryant literature. Analyze when rollback is correct for LIF voltage, refractory time, generated events, floating-point accumulation, synaptic trace/eligibility, RNG, and real-time output. Define forward/reverse mapping, LP state fields, GVT/commit discipline, anti-message conservation and forced-rollback golden test. Show a causality proof sketch or precisely state that proof is missing. Compare to EXP-0004 pairwise watermark and barrier baselines; do not assume 'optimistic' is faster. No benchmark runs; research PR with review gates.

## C — Memory and long-horizon substrate scout
Inspect NEST _hpc/_hom synapses, plasticity-history flush methods, Brian event-driven synaptic ODE codegen, Arbor cell grouping and CoreNEURON SoA approaches. For every technique specify resident per-neuron/per-edge/per-compartment state, silent-history scaling, monitoring/checkpoint overhead and failure under sustained feedback. Predict differentiating workload and measurement, estimate from *documented* representation or label unknown; do not infer measured RSS. Cross-reference EXP-0004 direct CSR and history negative results. Do NOT assume a smaller memory model has unchanged semantics.

## D — Independent experimental statistician / reproducibility reviewer
Adversarially review EXP-0005 result schema v2 proposal, workload hashes, baseline and timing, warmup, run ordering, ceiling tests and failure retention. Draft rejection examples: identical benchmark_id with different raw fixture hashes, speedup claimed on different spike counts, time-grid parity claim, process children missing from RSS, optimistic processed events without committed counts. Specify pairing, bootstrap CIs, multiple comparisons and power limitations. Build an independent *test plan*, not a second generated adapter. Recommend changes before scale.

## E — Mac / multirate and accelerator explorer (deferred from Linux implementation)
Investigate portable C++ or native compiled CPU kernels on Apple M4 Pro 48GB; compare SIMD, Apple Accelerate, Metal and MLX feasibility **only with verified supported APIs**. Propose one minimal field-equivalent kernel vs portable baseline with compile and execution boundaries, memory pressure of unified RAM, and energy measurement availability. No GPU acceleration presumed; no hardware purchase. Evaluate native mechanism transfer, not a 'framework speed winner'. Do not execute until separate Mac approval.

## F — Scientific relevance skeptic
Ask: does supporting a million inert nodes help long-term adaptive activity? Define at least two **bounded cognition-relevant** pilot workloads: extended silence/replay/state intervention and temporal order/discrimination with plasticity/history; include simpler frozen-memory and time-aware recurrent controls. Clarify what persistent endogenous computation could explain that storage-only models could not. Separate evidence of causal state change from thought, intelligence and self-observation. No implementation; report potential falsifiers.
