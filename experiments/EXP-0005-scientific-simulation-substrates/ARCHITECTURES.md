# EXP-0005 — Comparative substrate architecture audit (pre-execution)

**Classification:** paper/documentation-verified architecture claims + hypotheses, NOT local benchmark results. Underlying project goal remains persistent, adaptive, causally meaningful computation, not simulation speed for its own sake.

| System | Native computational contract | Architectural transfer candidate | Likely confound / critical limitation |
| --- | --- | --- | --- |
| **NEST 3.x** | Hybrid time-driven neuron updates, event-driven synapse updates and buffered spike exchange in min-delay-aligned intervals; OpenMP/MPI infrastructure, precise-spike models distinct from grid models | Delay-window batching, delivery buffers, memory-lean homogeneous/HPC synapse variants, event-triggered plasticity flush / history | Fixed resolution/grid and precise variants have different numerical behavior; standard STDP ignores precise spike fraction; graph construction and first Simulate preprocessing may dominate |
| **Brian 2** | Equations in Python generate runtime code and standalone C++; synaptic ODE marked event-driven updated only on spike where mathematically suitable | Domain-specific compiled dynamics, declarative hybrid state, per-synapse eligibility traces | Generated build overhead, code/cache variance, time-grid scheduling, C++ standalone/OpenMP backend caveats; event-driven tag valid only for independent linear equations in Brian |
| **Arbor** | Recipe builds cells lazily/parallel; CPU/GPU cell groups with domain decomposition, spike exchange between cells, numerical integration for cable cells and point LIF | Separating cell-internal ODE integration from network exchange; contiguous cell group kernels, morphology-native local state | LIF cell cannot host arbitrary channels/synapse mechanisms; cable neurons have multiple compartments so comparing raw N is misleading; MPI spike-allgather layout and epoch/delay costs |
| **ROSS (Time Warp)** | Timestamped logical processes (LPs), MPI PDES with sequential/conservative/optimistic modes, reverse computation, GVT/fossil collection | Sparse causality without global minimum-delay barriers, reversible adaptation, delayed commit of irreversible effects | Rollback cost and memory can destroy gains; reverse handler must undo all state/RNG effects; GVT before output; topology with frequent feedback may thrash |
| **CoreNEURON (deferred)** | Array/SoA-friendly compute backend within NEURON, fixed step, vectorization and optional GPUs | Compiled state layout, detailed mechanism kernels and model interoperability | Integration complexity; CPU vs GPU comparisons require true supported build and equivalent models |
| **GeNN (deferred)** | Source-generated simulator emphasizing accelerators | Generated plasticity/device-side neuron updates | AMD iGPU/Mac portability not guaranteed; no CUDA presumed |
| **Other alternatives** | SUNDIALS/CVODE-style adaptive integration, event-driven exact linear integration, multirate regional scheduler | Stiff/nonlinear accuracy vs sparse event overhead, selective local updates | Requires separate prototype; cannot claim a native framework has these by default |

## Directly checked primary-source constraints
- NEST resolution h and minimum synaptic delay d_min establish timing/communication cadence. Its 'precise' model family is not synonymous with arbitrary exact timestamp parity; identify selected cell model and actual synapse precision. NEST v3.10 was the site-reported release as of 2026-10; pin actual installed API. References in [SOURCES.md](SOURCES.md).
- NEST's built-in separate construction/simulation timers and first-simulation connection preprocessing require a **cold-first-call** and **warm repeated run** contrast. Classify rate changes if first-call setup contaminates simulation-only number.
- NEST homogeneous variants share synaptic parameters; _hpc variants trade model flexibility for memory. Treat these as separate *semantically documented* variants.
- Brian 2 standalone generation is real emitted C++ (not a label for an EXP-0004 wrapper). Time-stepped neuronal integration differs from pure asynchronous event LIF unless the equation/method supports exact integration. Disable speculative OpenMP performance claim until version-specific tests; inspect generated code and report its hashes.
- Arbor native recipe and cell-group domain decomposition makes 'one simulation neuron' a poor normalization for detailed compartmental modeling. Test lif_cell first, then one **native cable** case with actual compartment count and solver settings; no custom fake 'Arbor engine'.
- ROSS uses forward/reverse callbacks, supports optimistic debug and reverse handler check in v8.1. A simulation that runs only sequentially or never rolls back has NOT validated Time Warp. Use explicit anti-message/commit/GVT sanity test with measured rollbacks.

## High-value architectural ideas missing or untested in EXP-0004
1. **Equation compiler / semantics-aware execution**: separate user-defined local ODE and synaptic update rules from engine scheduling, generate specialized kernels, measure compile amortization and mechanism correctness.
2. **Two-clock system**: continuous or adaptive integration *inside cells* plus event scheduling *between regions*; expose solver error and lookahead to controller.
3. **Plasticity-aware memory placement**: edge-local STDP traces vs source-shared filtered traces, sparse update and flush events to limit silence-era history retention. Semantics may differ; measure it.
4. **Speculative causal execution**: optimistic LP computation across high cross-region traffic, reverse state including synaptic traces and RNG, GVT-based readout publication; bound fossil-collection backlog.
5. **Hierarchical/multirate simulation**: active subgraphs at high resolution, quiescent neurons with lazy state extrapolation, slow modulatory state. Requires mathematical error bound; not a free skip.
6. **Recording cost as first-class model dimension**: monitoring/traces/checkpoints can dominate long experiments; measure monitor-off/minimal/detailed and committed-output correctness.
7. **Event density x integration complexity x horizon phase diagram**: EXP-0004 mainly illuminated topology and event queues. EXP-0005 should identify where solver, compiled kernel, synchronization and plasticity memory dominate.
8. **Scientific capability frontier vs throughput**: a slower simulator might uniquely support a richer, valid model and therefore unlock a novel experiment.

## Threat model for inference
'Exact parity' is prohibited across nonidentical time grids, solver algorithms, spike crossing policies, or native model defaults. Benchmark equality needs a **semantic map** and multi-resolution error curves; the correct conclusion may be 'non-comparable'. Separate kernel event, synaptic event, neuron update, solver step, spike, network edge traversal, rollback and committed event counts. Optimistic *processed* event throughput can be larger than useful committed throughput. Report both.

## Suggested order / effort (relative, not a deadline)
WP-00 contracts and independent oracle first; WP-01 NEST then WP-02 Brian to establish distinct spike and ODE pathways. WP-03 Arbor after those; WP-04 ROSS gated by proof and complexity. WP-05 cross-backend audit starts once 2 backends complete. ROSS is intentionally late/high-risk; it may be stopped after correctness failure without delaying useful synthesis. Optional Mac portable C++/SIMD experiment and broader native frameworks follow evidence, not presumption.
