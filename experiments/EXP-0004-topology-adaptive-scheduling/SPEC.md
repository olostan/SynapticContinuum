# EXP-0004 — Connectivity topology, event locality, and adaptive region ownership

**Status: PREREGISTERED DESIGN ONLY — NOT RUN.** 2026-10-23. Governed by ../../EXPERIMENTATION.md. Depends on EXP-0003's merged C++ engines and the reviewed Linux findings. Do not confuse performance with cognition or assume that a brain-inspired graph is necessarily easier to execute.

## Research question
How do **network topology**, activity localization, and partitioning/scheduling policy interact to determine (a) *actual* exploitable event parallelism and (b) how faithfully causal event evolution can be executed? Can dynamic region ownership substantially improve **self-scaling** over a correct serial reference on six physical cores, rather than merely outperforming a contended mutex queue?

## Competing, falsifiable hypotheses
- H1 **Topology**: At matched N, directed edge count, degree sequence where possible, event input, propagation delays and *observed* event workload, community-structured graphs reduce cross-region messages and increase causal parallel slack compared with uniformly random graphs. May fail if recurrent hubs synchronize modules or bursts spread globally.
- H2 **Partitioning**: Community-aware or activity-informed partitions outperform contiguous node-ID ownership when they reduce *measured active event cuts*, not merely edge cuts. Overhead of detection/repartition may outweigh benefits.
- H3 **Execution**: Persistent workers, numerous fine-grained logical regions and async dependency-safe dispatch improve owner **self-speedup** versus EXP-0003 global barrier epochs. May fail due expensive conservative causality or contention.
- H4 **Adaptive placement**: Selective migration/split/merge or lease-based exclusive region ownership benefits skewed workload after *accounting for migration, synchronization and instrumentation*; may lose to static locality-aware partitioning.
- H5 **Order relaxation** (clearly separately labeled model): bounded timestamp disorder can improve throughput relative to causal-only ordering, but may alter spike trajectories, temporal discrimination, plasticity and endogenous dynamics. No claim of scientific equivalence or functional robustness without task results.
- H6 **Real topology**: Measured properties of publicly accessible anatomical connectome data may differ substantially from synthetic benchmarks; real neuronal adjacency does not by itself provide functional weights, delays, trained behavior, or proofs of cognition.

**Stage 1: controlled topology generator, comparable work.**
- Directed Erdős–Rényi/fixed-outdegree random graph as baseline.
- Watts–Strogatz-style rewired lattice/small-world network adapted explicitly to directed sparse edges; rewiring p={0,0.01,0.1,0.5,1}. Note high clustering does not guarantee modularity or good cuts.
- Planted community/stochastic block model with within/between ratios, hierarchical modular model, and six disconnected modules as upper-bound scheduling control; planted labels retained as oracle partition.
- Degree-preserving directed rewiring control (preserve in/out-degree sequence where feasible), and randomized node-ID permutation: ensure observed gains don't arise merely from contiguous IDs.
- Optional hub/heavy-tailed degrees if within memory/time budget; explicitly label graph generation assumptions.
- Hold N, actual directed edge count, input activation schedule, weight and delay assignment policy fixed for paired tests; when induced propagation differs, **report the actual event count/spikes separately** and include replay of pre-generated workload to isolate dispatch from topology-driven dynamics. No normalization alone can make differing neural trajectories equivalent.

**Stage 2: partition strategies.** Naive contiguous IDs; deterministic hash/random assignment; planted-oracle community labels (synthetic only); graph-cut optimizing method (deterministic greedy acceptable, record time); observed-event-traffic partitioning trained on a **separate warmup trace** only, scored on held-out activity periods. Compare same worker counts, balanced state sizes and same N/edges. Measure edge cut and *weighted event traffic cut*, partition skew, amount of shared target activity, and migration cost. No retrospective use of benchmark-period traffic to optimize the same benchmark.

**Stage 3: scheduler variants.** Baselines serial and EXP-0003 static owner+barriers; persistent worker pool with region-local queues, regions >> worker count, exclusive ownership map, lossless timestamped cross-region mailboxes, no unprotected cross-worker writes; optional dispatch cost model and bounded region migration / split / merge. Separate (a) static region->worker assignment, (b) migration, (c) finer granularity, (d) barrier removal; each independently switchable and benchmarked. Zero-delay cross-region edges must be correctly supported or rejected explicitly with documented positive lookahead, never replaced with invented epsilon. Region migration needs epoch/version, drain/handoff and in-flight message safety. Deadlock detection/timeouts, deterministic replay and same-event count vs serial reference required. Work stealing only by ownership transfer at a safe boundary.

## Quantitative success/falsifiers, separate from scientific claims
- Primary outcomes: serial-to-owner **self-speedup** for same validated workload on W=1/2/4/6, confidence spread across seeds/repeats, and fractional worker CPU utilization, barrier/idle time, cross-region event rate, migration time. Compare against old owner and shared-queue implementations as contextual data only; don't call 5x versus bad mutex implementation 5x parallel scaling.
- Prespecified *engineering aspiration*, not prediction: >=3x W=6 self-speedup on disconnected high-workload control. Failure triggers profiler investigation; **no tuning away failed cases**. Real modular graph success threshold exploratory, report all curves.
- Graph topology metrics: clustering coefficient (sampling method and uncertainty for large N), mean shortest path via fixed-seed sampling not dense APSP, assortativity if computed, modularity, in/out-degree distributions, undirected projection rules when needed. Confirm graph is actually small-world relative to relevant matched random/lattice controls instead of naming it small-world by generator choice alone.
- Correctness: exact serial state/spike/event trace and deterministic tie rules for strict mode on small adversarial fixtures including zero-delay rejection, cross-region feedback, simultaneous events, hot hub, migration during incoming message; hash alone insufficient. Large-run digests, task readouts and compare event counts/causal errors. No data races (TSan where feasible), tests run under repeated randomized schedules.
- Claims about speed and biology are conditional on metrics. Report if claimed higher parallelism doesn't materialize, if topology changes event volume, or if constrained causality prevents >1x speedup.
- No consciousness/cognition conclusions from faster execution, connectome anatomy or spontaneous spiking.
